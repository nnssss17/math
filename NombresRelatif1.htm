Les nombres relatifs

Objectifs

ü  Utiliser le vocabulaire des nombres relatifs

ü  Comparer des nombres relatifs

ü  Se repérer sur une droite ou sur un plan

ü  Manipuler des sommes et des différences de nombres relatifs

Définition

Définition Un nombre positif est un nombre supérieur à zéro.

On le reconnait à son signe + ou son absence de signe.
Un nombre négatif est un nombre inférieur à zéro.

On le reconnaît à son signe 

Un nombre relatif est un nombre positif ou négatif

Zéro est à la fois négatif et positif. Cest donc un nombre relatif

 

Définition Distance à zéro : La distance à zéro dun nombre positif est ce même nombre.

La distance à zéro dun nombre négatif est ce même nombre, sans le signe 

 

        Propriété La distance à zéro est un nombre positif

 

Comparer des nombres relatifs

   Les nombres positifs se rangent dans le même ordre que leurs distances à zéro

   Les nombres négatifs se rangent dans lordre contraire de leurs distances à zéro

   Un nombre négatif est toujours plus petit quun nombre positif

Opposé dun nombre

Définition Lopposé dun nombre est le nombre qui a la même distance à zéro que ce nombre, mais dun signe différent.

Droite graduée

Définition Une droite graduée est une droite sur laquelle on a défini :
- Un point dabscisse 0, appelé origine
- Des points régulièrement espacés, appelés graduations.
Lorigine sépare la droite en 2 demi-droites graduées, une pour les abscisses des nombres positifs, lautre pour les abscisses des nombres négatifs.

 


Se repérer dans le plan sur un repère orthogonal

Définition Un repère orthogonal est constitué de 2 droites graduées perpendiculaires. La droite horizontale est appelée laxe des abscisses. La droite verticale est appelée laxe des ordonnées.
Chaque point du plan a ainsi 2 coordonnées :
Une abscisse, qui est la coordonnée horizontale
Une ordonnée, qui est la coordonnée verticale

 

  Méthode : Pour déterminer les coordonnées dun point, on trace les perpendiculaires à chacun des axes passant par ce point. Les coordonnées sont les points dintersection de ces perpendiculaires avec les axes.

  On note les coordonnées : A(abscisse ;ordonnée) par exemple A(-2 ;3)

Définition Le résultat de laddition de deux nombres relatifs est un nombre relatif appelé somme.

Soustraction de deux nombres relatifs

Définition Le résultat de la soustraction de deux nombres relatifs est un nombre relatif appelé différence. Il est le résultat de laddition du premier nombre et de lopposé du deuxième.
þ  Soustraire un nombre relatif revient à additionner son opposé
